# Zombie Shooter

A 2D arcade shooter built with Python and Pygame. Zombies fall from the top of the screen. Move left and right and shoot them before they reach you.

![Gameplay screenshot](screenshot.png)

## Features
- Player movement and shooting at 60 FPS
- Zombies spawn at random positions
- Collision detection between bullets, zombies, and the player
- Health, score, and play-time display
- High score saved between sessions (file I/O)
- Start screen, custom window icon, and background music

## How to run
1. Install Python 3.
2. Install Pygame:
   ```
   pip install pygame
   ```
3. From this folder, run:
   ```
   python zombie_shooter.py
   ```

## Controls
| Key | Action |
|---|---|
| Click | Start game |
| ← / → | Move |
| Space | Shoot |
